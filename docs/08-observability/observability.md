# Deliverable 8 — Observability

## DORA metrics
- Deployment frequency
- Lead time for changes
- Change failure rate
- Time to restore service

## Additional metrics
Build duration, queue time, gate failure rate, vulnerability counts, rollback rate, canary duration, SLO burn, error rate, p99 latency, saturation, deployment success and MTTR.

## Dashboards
Engineering: real-time service and deployment health.
Management: delivery and reliability trends.
Regulatory: gate evidence, exceptions and audit traceability.
